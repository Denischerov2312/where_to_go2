# Куда пойти/Where to go
Проект представляет собой интерактивную карту с достопримечательностями и интересными местами.
Сайт показывает самые красивые и интересные места мира. На главной странице удобно просмотривать где находятся различные места, можно просмотреть их краткое описание, также увидеть картинки.
Имеются большие возможности для редактирования. Django админка позволяет легко редактировать, добавлять и изменять информация о достопримечательностях.

## Запуск на локальном сервере
 - Для запуска проекта вам понадобится Python. Инструкция по [установке Python](https://skillbox.ru/media/code/kak_zapustit_python/).
- Скачайте репозиторий с GitHub. Если у вас установлен git bash, можете использовать команду:
  ```bash
  git clone https://github.com/Denischerov2312/where_to_go2.git
  cd where_to_go2
  ```
- Создайте и активируйте виртуальное окружение(необязательно)
  ```
  python - m venv venv
  venv\Scripts\activate
  ```
- Затем используйте pip (или pip3, есть конфликт с Python2) для установки зависимостей:
  ```sh
  pip install -r requirements.txt
  ```
 - Настройте виртуальное окружение. Создайте файл `.env` в корневой папке проекта. Минимальные данные, которые нужны для запуска:
  ```
  SECRET_KEY=ВАШ_СЕКРЕТНЫЙ_КЛЮЧ
  ```
- Примените все миграции командой:
```
python manage.py migrate
```
- Командой ниже загрузите данные для карты, иначе она будет пустая. Так можете сами создать json файл. Пример такого файла ниже.
```
python manage.py load_places
```
- Запустите сервер командой:
```
python manage.py runserver
```

## Настройка переменных окружения
К настройке доступно всего 3 переменных.
Запишите их в файл `.env` в формате `ПЕРЕМЕННАЯ=ЗНАЧЕНИЕ`.
- `DEBUG` - Отвечает за то, в каком режиме запустится сервер. Принимает `True` или `False`. По умолчанию `False`.
- `SECRET_KEY` -  Ключ доступа. У каждого индвидуальный
- `ALLOWED_HOSTS` - Список адресов, для которых сайт имеет право отвечать, по умолчанию `['127.0.0.1', 'localhost']`

## Описание данных
Каждая точка на карте - это отдельный json файл. Данные в нём хранятся в формате json.

- `title` - Название точки, видно при наведении на нёё.
- `imgs` - Список с ссылками на изображения для этого места.
- `description_short` - Короткое описание места.
- `description_long` - Основное описание места в  формате html, которое открывается при нажатии на точку. В нём содержится основная информация
- `coordinates` - Словарь с ключами `lng`(долгота), и `lat`(Широта). Указывается дробное значения, с разделителем точкой(`.`).
